## Version und Betriebsmodelle

Vorlagenbasis: **8.0.x (Beispiel: 8.0.10)**, Ordner [`Version_8.0.x_Enterprise`](Version_8.0.x_Enterprise/).

- [Linux nativ, Cluster mit drei Knoten](Version_8.0.x_Enterprise/Linux/README-de.md)

Diese Anleitung behandelt Redis Enterprise und dessen Verwaltungswerkzeuge. Sie enthält kein Docker-Compose-Setup und keine Konfiguration für Redis Open Source.

## Versionsgültigkeit und Prüfstand

Die Anleitung unter `Version_8.0.x_Enterprise` hat 8.0.10 als dokumentierten Beispielstand. Andere Builds innerhalb von 8.0.x müssen auf abweichende Einstellungen und Verwaltungsabläufe geprüft werden.

| Plattform / Variante | Versionszuordnung | Prüfstand am 16.11.2026 |
|---|---|---|
| Linux nativ, drei Knoten | Redis Enterprise 8.0.10 | Dokumentation statisch geprüft; kein nativer Cluster-Laufzeittest und keine Build-spezifische Freigabe. |

Neue Zuordnungen und abweichende Vorlagen folgen der [gemeinsamen Versionsregel](../README-de.md#versionen-und-konfigurationsordner).
